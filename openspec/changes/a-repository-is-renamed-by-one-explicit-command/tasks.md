# Tasks

Build the tasks in order. Each check runs as written, from the worktree's root. A logic or contract check is `devenv shell -- bash -c 'moon run tests:venv && tests/.venv/bin/python -m pytest -q -p no:cacheprovider <node>'` on the node it names, and it passes when pytest reports no failure. An end-to-end check is `tests/suite <name>`, which passes when it ends with "0 failed". The verify stage runs the repository's whole checks once every task is done. Never run `wt submit --help`.
