# Tasks

Work the tasks in order, each in the place's worktree, from its root. Each check runs as written there. A logic or contract check first syncs the tests' venv through moon (`tests:venv`), then runs one test file's class or case by its pytest node id. An end-to-end check runs one test by name through `tests/suite`. Tick a task once its check passes. Submit nothing: Flume submits the place once its last stage delivers.
